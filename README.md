# Эмулятор командной оболочки ОС (Вариант №23)

Учебный проект по дисциплине «Конфигурационное управление».
Представляет собой эмулятор командной строки UNIX-подобной операционной системы с графическим интерфейсом (GUI), работающий с виртуальной файловой системой (VFS) в оперативной памяти.

---

## 1. Общее описание

Приложение имитирует работу терминала UNIX-подобной ОС. Все операции с файловой системой происходят строго в оперативной памяти — исходные файлы и директории на диске не модифицируются. 

Эмулятор поддерживает:
- Графический интерфейс на базе библиотеки `tkinter`.
- Отображение текущего имени VFS в заголовке окна.
- Интерактивный ввод команд с парсингом аргументов.
- Загрузку VFS из реальной папки на диске или создание дефолтной VFS в памяти.
- Выполнение автоматических стартовых скриптов с поддержкой комментариев.
- Набор базовых и дополнительных команд (`ls`, `cd`, `history`, `uptime`, `tail`, `chown`).

---

## 2. Требования и настройки

### Зависимости
- **Python 3.10+**
- Встроенный модуль `tkinter` (поставляется вместе с Python)

### Параметры командной строки

При заполнении параметров при запуске доступны следующие флаги:

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `--vfs` | Путь к реальной директории на диске для загрузки VFS | `None` (создается дефолтная VFS в памяти) |
| `--script` | Путь к стартовому скрипту с командами для автоматического выполнения | `""` (без скрипта) |

## 4. Поддерживаемые команды

- `ls [path]` — вывод содержимого текущей или указанной директории.
    
      
    
- `cd [path]` — смена текущей рабочей директории (поддерживаются `.`, `..`, `/`).
    
      
    
- `history` — вывод истории всех введенных команд в текущей сессии.
    
      
    
- `uptime` — вывод времени работы эмулятора с момента запуска.
    
      
    
- `tail [path]` — вывод последних 10 строк указанного текстового файла.
    
      
    
- `chown <owner> <path>` — изменение владельца файла или папки в памяти.
    
      
    
- `exit` — завершение работы эмулятора и закрытие приложения.
    
      
    

## 5. Примеры использования

### Интерактивный режим

После запуска окна эмулятора можно вводить команды последовательно:

```
$ cd home
$ cd user
$ ls
welcome.txt  notes.txt
$ tail welcome.txt
Hello, VFS!
$ chown admin welcome.txt
Owner of 'welcome.txt' changed to 'admin'
$ uptime
Uptime: 0m 45s
```

### Пример стартового скрипта (`script.txt`)

Файл скрипта поддерживает комментарии, начинающиеся с символа `#`:

```
# Автоматическое тестирование VFS
ls
cd home/user
tail welcome.txt
chown admin welcome.txt
history
uptime
```
